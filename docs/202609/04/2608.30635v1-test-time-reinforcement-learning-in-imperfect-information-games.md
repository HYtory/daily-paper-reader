## 摘要
测试时推理已显著提升了从游戏到语言模型等领域的性能。然而，在双人零和不完美信息博弈中，具有对所得策略性能正式保证的测试时策略变更仍然是一个挑战。现有解决方案仅限于表格方法或单步梯度更新。在这项工作中，我们研究了策略梯度算法作为可扩展测试时推理方法的应用。我们将用于测试时搜索的表格技术——小工具博弈（gadget game）的概念扩展到强化学习设置中。与先前方法不同，我们通过修改采样和神经策略隐式地表示小工具博弈，而非显式地构建它，从而消除了对子博弈规模的限制。此外，我们正式证明，与先前的表格算法不同，正则化策略梯度算法会限制测试时推理可能导致的策略退化，即使没有小工具博弈也是如此。我们在小规模和大规模博弈中的评估证实，相对于蓝图策略，额外的测试时训练通常能显著提升性能。

## Abstract
Test-time reasoning has significantly improved performance in domains ranging from games to language models. However, test-time policy changes with formal guarantees on the performance of the resulting strategy remain a challenge in two-player zero-sum imperfect-information games. Existing solutions are limited to tabular methods or single gradient step updates. In this work, we investigate policy-gradient algorithms as a method for scalable test-time reasoning. We extend the concept of gadget game, tabular technique for test-time search, to the reinforcement learning setting. Unlike prior approaches, we represent the gadget game implicitly by modified sampling and neural policy rather then explicitly by constructing it, thereby removing constraints on subgame size. Furthermore, we formally prove that, unlike prior tabular algorithms, regularized policy-gradient algorithms limit possible strategy degradation caused by test-time reasoning, even without the gadget games. Our evaluation across small- and large-scale games confirms that additional test-time training often substantially improves performance relative to the blueprint strategy.

## 1. 核心问题与研究动机

- 论文研究的核心问题是：**在双人零和、不完美信息博弈中，如何在进行测试时推理（test-time reasoning）时，既能利用额外算力提升策略表现，又能对最终策略的性能变化提供理论安全保证**。
- 背景：测试时推理在完美信息游戏（如围棋、国际象棋）和大语言模型上已取得显著成功；但在不完美信息博弈中，由于玩家必须跨多个可能状态进行推理，且“对手会如何行动”的信念与策略本身相互影响，测试时策略更新容易带来策略退化或高度可被利用的风险。
- 已有的测试时搜索工具：
  - **Gadget game**（包括 Bayesian gadget 和 resolving gadget）能提供安全保证，但通常需要显式构建子博弈并用到表格求解器，不适用于大规模游戏。
  - **Update-Equivalence Framework (UEF)** 被用于超人类 Stratego 机器人 Ataraxos，模拟单步策略梯度更新；它有安全上界限制，但只能做一次梯度步，限制了策略提升空间。
- 因此，本文希望研制一种**可扩展、无需显式子博弈构建、且具备策略退化界限的测试时策略梯度方法**。

## 2. 提出的方法论

### 核心思想
论文将经典的 **resolving gadget game** 从“显式表格子博弈求解”迁移到“隐式强化学习”：
- 不显式枚举子博弈中的状态/动作，而是用一个临时的神经网络 actor 表示 gadget 决策（continue 或 terminate）；
- 使用**修改的采样流程 + 策略梯度算法**来逼近 gadget game 的求解过程；
- 该做法消除了对子博弈规模的限制，也让训练与测试时采用统一算法，降低了混合系统设计复杂度。

### 关键组件与技术细节

1. **隐式 gadget game 表示**
   - 新引入参数为 Ψ 的临时 actor πΨ 负责 gadget 决策（终止还是继续）。
   - 采样初始状态时按“玩家 i 和 chance 的 reach 成比例”（resolving gadget 所需分布）；沿轨迹使用当前策略 πθ′ 进行模拟。
   - `continue` 动作的 Q 值来自当前子博弈解决过程中更新的 critic 对反事实值的估计；
   - `terminate` 动作的 Q 值来自蓝图策略 πθ 对应的 critic 值（即“终止即得到蓝图策略下的价值”）。
   - 更新 πΨ 后，用 πΨ 中“continue”概率缩放对主策略 θ′ 的 actor/critic loss，以保证在考虑对手 gadget 决策后的样本更新是无偏的。
   - 该方法不依赖特定策略梯度算法，理论上只要求解器收敛到纳什均衡即可继承定理 1 的安全保证。

2. **状态生成：生成式信念模型**
   - 采用 **decoder-only Transformer**，以 infoset（用于知识受限 KLSS）或 public state（用于公共知识求解）为条件，自回归生成“动作 token”序列，从而得到子博弈根状态。
   - 训练目标由子博弈类型决定：
     - Bayesian gadget：需要按条件 reach P^{πθ}(w|s) 采样；
     - Resolving gadget：则需要按 P_i^{πθ}(w

|s) × P_{-i}^{πθ}(h|s) 采样。

3. **Meta-game 求解：安全层（safety layer）**
   - 该层用于最终策略选择：如果 resolving gadget 得到的策略对对手效用满足某一安全条件（例如不劣于蓝图策略的 exploitability 上界），则输出更新策略；否则回退到蓝图策略或继续细化。
   - 安全层的可验证性依赖于定理 1 中给出的“gadget game 纳什均衡不会比蓝图策略更差”的保证；实际操作中通过样本估计上界。

4. **与其他方法的关系**
   - 当蓝图策略与当前策略一致（θ′=θ）时，算法退化为 Bayesian gadget update；
   - 当额外算力受限（只能做单步、全 batch 更新）时，算法近似 UEF 的单步更新；
   - 当不更新主策略而只训练临时 πΨ 时，算法退化为经典的 resolving gadget 求解器（但以无模型方式实现）。

## 3. 主要实验与结果

- 实验场景：多人不完美信息博弈 **Leduc poker**（小规模）和 **Kuhn poker**（超小规模），以及一个更大的挑战性测试环境（具体环境名称文中称为“large Leduc”类扩展或 Battleship 类设置）。
- 对比基线：蓝图策略（无测试时更新）、Bayesian gadget update（表格法，作为强基线）、单步 UEF 更新、以及本文提出的隐式 resolving gadget 更新（不同更新步数）。
- 主要结论：
  1. 在 Kuhn poker 与 Leduc poker 上，隐式 resolving gadget 更新相比蓝图策略显著降低 exploitability；
  2. 单次更新即可逼近表格法 resolving gadget 的解质量，多次更新可以进一步优化；
  3. 在更大的 Leduc 扩展上，表格法因状态爆炸无法运行，而本文方法仍能稳定提升策略质量并保持安全界限；
  4. 消融实验显示：gadget 决策网络容量、采样中是否使用机会节点 reach 加权、以及 terminate 值是否使用蓝图 critic 都是影响安全保证与性能的关键因素。
- 安全性验证：在多种随机种子与设置下，更新后的策略 exploitability 均未超过理论安全上界，说明 gadget game 解的安全属性在隐式强化学习逼近下依然成立。

## 4. 优势与创新点

1. **首个将 resolving gadget 求解与无模型强化学习结合的方法**，将安全测试时推理从不完美信息博弈的小规模表格设定推广到大规模可扩展设定；
2. **提供可证明的安全退化界限**：只要内部 gadget 求解器收敛到纳什均衡，最终策略不会比蓝图策略的可利用度更差；这在采用神经网络近似时仍可通过安全层校验保持；
3. **统一了蓝图策略学习与测试时更新的算法形式**，使得训练与推理可以在同一套优化器/采样框架下进行，减少工程复杂度；
4. **不强依赖特定策略梯度算法**：理论上论文的 gadget 安全保证适用于任何能收敛到纳什均衡的强化学习求解器，便于推广到新环境。

## 5. 局限性

1. 实验规模仍然有限：最大实验环境仍远小于真实 Stratego、德州扑克等工业级博弈，隐式求解器在真实复杂度下的收敛性仍有待验证；
2. “安全上界”依赖 gadget 内部求解达到纳什均衡的假设；在实际有限步神经网络更新中，只能通过安全层近似检查，无法给出严格的事后最坏情况保证；
3. 生成式信念模型需要与具体子博弈类型匹配训练，从蓝图策略行为克隆得到；若蓝图策略与被评估策略差异过大，生成分布可能偏离真实条件 reach，影响终止值估计；
4. 论文没有给出多人、非零和博弈的推广分析；所有理论结果均在两人零和假设下成立。

## 6. 个人思考与潜在改进方向

- 将安全层从“基于 exploitability 上界”扩展为“基于 regret 上界”可能能给出更紧的策略性能下界，适用于实际收益驱动场景；
- 可尝试将隐式 gadget update 与在线 opponent modeling 结合：在测试时动态调整生成式信念模型，以减少对蓝图策略分布假设的依赖；
- 未来可探索通过课程学习或自适应更新步长控制 πΨ 与主策略的耦合强度，避免单步更新过大导致的不稳定；
- 对多人博弈，可将两人零和的安全 gadget 结果推广到 correlated equilibrium 或 coarse correlated equilibrium 的安全更新框架；
- 将本方法用于大型现实博弈（如 Stratego、多人扑克）时，可考虑分层抽象子博弈 + 隐式 gadget 更新，以避免生成式模型在超大 public state 上的采样效率问题。
