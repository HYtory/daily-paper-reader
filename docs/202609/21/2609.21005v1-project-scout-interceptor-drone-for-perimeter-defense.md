## 摘要
未经授权无人机（UAV）的迅速激增，催生了对用于周界防御的稳健且抗干扰反无人机系统日益增长的需求。本文提出SCOUT（面向优化无人机跟踪的空间计算，Spatial Computation for Optimized UAV Tracking），一种集成于ROS的机载感知与控制框架，用于对来袭无人机进行实时空中防御。SCOUT直接在防御无人机上执行视觉检测、目标关联、航迹滤波和控制指令生成，无需依赖外部传感基础设施或地面站计算。为提供稳定的控制输入，感知流水线将TensorRT加速的无人机检测与基于ByteTrack的关联以及轻量级航迹保持状态机相结合。该状态机可剔除目标的突变跳变，并在检测暂时退化期间维持短期目标连续性，从而减少由误检测或目标切换引起的不稳定控制响应。我们通过执行平面“守门员”拦截策略的集成硬件部署，对所提架构进行评估。在此设置下，防御无人机跟踪来袭目标并调整其运动，以在受保护边界附近保持阻挡构型。真实飞行结果表明，SCOUT在实时机载检测速率下，在92.2%的帧中保持有效目标检测，证明了视觉跟踪与闭环控制用于无人机周界防御的可行性。端到端周界防御操作的视频演示可在线获取：https://figshare.com/s/497befc033091fc0b84f

## Abstract
The rapid proliferation of unauthorized unmanned aerial vehicles (UAVs) has created a growing need for robust, jamming-resistant counter-UAV systems for perimeter defense. This paper presents \textbf{SCOUT} (Spatial Computation for Optimized UAV Tracking), a ROS-integrated onboard perception and control framework for real-time aerial defense against incoming UAVs. SCOUT performs visual detection, target association, track filtering, and control command generation directly onboard the defender UAV, without relying on external sensing infrastructure or ground-station computation. To provide stable control inputs, the perception pipeline combines TensorRT-accelerated drone detection with ByteTrack-based association and a lightweight track-retention state machine. The state machine rejects abrupt target jumps and maintains short-term target continuity during temporary detection degradation, reducing unstable control responses caused by false detections or target switching. We evaluate the proposed architecture through an integrated hardware deployment executing a planar ``goalkeeping'' interception strategy. In this setting, the defender UAV tracks the incoming target and adjusts its motion to maintain a blocking configuration near the protected boundary. Real-world flight results show that SCOUT maintains valid target detections for 92.2\% of frames while operating at real-time onboard detection rates, demonstrating the feasibility of visual tracking and closed-loop control for UAV perimeter defense. A video demonstration of the end-to-end perimeter defense operation is available online. https://figshare.com/s/497befc033091fc0b84f

## 2. 方法论

### 2.1 核心思想

- 将深度学习小目标检测、轨迹关联、异常值过滤和自主控制统一在一个机载流水线中，而不是把它们当作独立预处理阶段。
- 输出不是孤立的逐帧检测框，而是**时间一致的目标中心误差估计**，供控制器生成稳定速度指令。
- 防御无人机采用平面“守门员”策略：只在横向-垂直平面运动，保持在受保护边界附近，形成对来袭目标的阻挡构型。

### 2.2 关键技术细节

- **检测器训练与微调**：
  - 使用 YOLO26n，在 DroneHunter、Det-Fly、DUT Anti-UAV、LRDDv3 四个数据集上预训练。
  - 再使用自采集的 DJI Neo 目标无人机图像进行微调，提高目标域适应能力。
- **实时感知与推理流水线**：
  - **异步丢帧管理**：使用严格单元素、线程安全队列，新帧到达时覆盖旧帧，保证下游检测始终处理最新图像，优先帧新鲜度而非处理每一帧。
  - **TensorRT 加速**：将 PyTorch 模型导出为 ONNX，再由 TensorRT builder 生成适配 Jetson SoC 的硬件引擎；采用 FP16 量化、层融合，将卷积、偏置和激活合并为统一执行核，减少内存带宽和核启动开销。
  - 相比初始 PyTorch 实现，TensorRT 引擎将流水线吞吐从约 22.5 FPS 提升到 48 FPS，提升约 114%。
- **ByteTrack 双池数据关联**：
  - 高置信池：\(S_t \ge 0.50\)；低置信池：\(S_{\min} \le S_t < 0.50\)，其中 \(S_{\min}=0.06\)。
  - 高置信检测用局部 Kalman 滤波匹配，低置信检测进行二次关联，以保留短暂视觉退化时可能仍对应目标的弱检测。
- **顺序几何滤波与离群点拒绝**：
  - 对候选框中心、宽、高按图像尺寸归一化。
  - 计算当前候选中心与上一验证轨迹中心的欧氏位移 \(d_t\)，以及上一验证框对角线 \(D_{t-1}\)。
  - 若 \(d_t > 2D_{t-1}\) 且当前置信度不高于过去 \(K=10\) 帧最大历史置信度，则判定为空间离群点并拒绝。
  - 若连续 \(T_{\text{stale}}=0.5\) s 无有效检测，则清除保留状态，允许跟踪器重新初始化。
- **拦截器控制**：
  - 图像中心设为 \((0.5, 0.5)\)，图像平面伺服误差为 \(e_u=c_x-0.5\)，\(e_v=c_y-0.5\)。
  - 控制器为饱和 PD 律：前向速度 \(v_x=0\)，偏航率 \(\omega_z=0\)，横向和垂直速度由 PD 项经 clip 限幅生成。
  - 小图像误差通过死区抑制，避免中心附近检测噪声导致振荡。
  - 仅在 OFFBOARD 模式下，通过 MAVROS 向飞控发送速度指令；检测过期则速度置零；垂直命令在高度边界处钳制。

### 2.3 算法流程概述

1. 防御无人机相机采集图像，ROS 话题输入。
2. 异步丢帧模块只保留最新帧。
3. TensorRT 加速 YOLO26n 进行无人机检测。
4. ByteTrack 对检测框进行跨帧关联，保留高、低置信候选。
5. 顺序几何滤波器拒绝空间跳变和低置信异常，维护短期目标连续性。
6. 输出稳定目标中心误差。
7. 平面守门员 PD 控制器生成横向、垂直速度命令。
8. 通过 MAVROS 发送至 Pixhawk 飞控，实现闭环防御机动。
