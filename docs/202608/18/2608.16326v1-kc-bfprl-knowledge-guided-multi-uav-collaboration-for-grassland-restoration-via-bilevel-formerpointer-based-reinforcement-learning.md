## 摘要
多无人机系统为大规模环境任务（如草原生态系统恢复）提供了可扩展的服务平台。然而，协调机队运行需要解决恢复面积最大化问题（RAMP）。这一非线性组合优化挑战因载荷相关的能量动态和异质生态退化而变得更加复杂。我们提出了一种新颖的知识引导协作式双级前指针强化学习框架（KC-BFPRL）来应对这一复杂性。KC-BFPRL采用分层范式，将RAMP分解为全局任务分配和局部恢复规划，其中局部恢复规划进一步分为上层轨迹规划和下层恢复区域分配。我们的专用架构配有一个基于Transformer的编码器，用于融合静态环境特征与动态无人机状态，以及一个通过稳健的演员-评论家框架训练的前指针网络解码器。通过嵌入生态优先级规则和启发式逻辑，KC-BFPRL实现了结构化热启动，解决了强化学习冷启动问题，同时确保严格约束满足。大量实验表明，KC-BFPRL持续优于最先进的基线，实现了更优的目标值和效率。在最复杂的U8-R160场景中，它保持了0.00%的最优性差距，且运行速度比MAPDP快近三倍，验证了其在大规模自动化生态恢复中的鲁棒性、可扩展性和实时适用性。

## Abstract
Multi-unmanned aerial vehicle (UAV) systems provide scalable service platforms for large-scale environmental tasks, such as grassland ecosystem restoration. However, coordinating fleet operations requires solving the restoration area maximization problem (RAMP). This non-linear combinatorial optimization challenge is complicated by payload-dependent energy dynamics and heterogeneous ecological degradation. We propose a novel knowledge-guided collaborative bilevel formerpointer reinforcement learning framework (KC-BFPRL) to address this complexity. Using a hierarchical paradigm, KC-BFPRL decomposes RAMP into global task allocation and local restoration planning, with the latter further divided into upper-level trajectory planning and lower-level restoration area allocation. Our specialized architecture pairs featuring a Transformer-based encoder that fuses static environmental features with dynamic UAV states, and a Pointer Network decoder trained via a robust actor-critic framework. By embedding ecological priority rules and heuristic logic, KC-BFPRL achieves a structured warm-start, solving the RL cold-start problem while ensuring strict constraint satisfaction. Extensive experiments demonstrate that KC-BFPRL consistently outperforms state-of-the-art baselines, achieving superior objective values and efficiency. It maintains a $0.00\%$ optimality gap in the most complex scenarios U8-R160 and operates nearly three times faster than MAPDP, validating its robustness, scalability, and real-time applicability for large-scale automated ecological restoration.

## 2. 方法论

### 2.1 核心思想
- 提出 **KC-BFPRL**（Knowledge-Guided Collaborative Bilevel Formerpointer Reinforcement Learning）框架。
- 采用**层级分解**策略：
  - 将 RAMP 分解为**全局任务分配**和**局部恢复规划**；
  - 局部恢复规划进一步分为**上层轨迹规划**和**下层恢复区域分配**。
- 采用 **“外部协作、内部智能”** 架构：地面控制中心（GCC）负责全局协同调度与动态地图更新，每架 UAV 使用基于 Transformer-Pointer 的 BFPRL 模型进行局部序列决策。
- 通过嵌入**生态优先级规则和启发式逻辑**，提供结构化热启动，缓解 RL 冷启动问题，并确保严格约束满足。

### 2.2 问题建模
- 将多 UAV 草原恢复建模为完全有向加权图 G = (V, A)，顶点包括基站 v0 和退化区域 Va。
- 每个区域 vi 具有退化程度 li ∈ [0.3, 0.8]（该区间内 UAV 播种有效），区域被离散化为若干单位圆 ci。
- UAV 从基站出发，携带最大能量 Emax 和种子载荷 Q，需在能量耗尽前完成任务并返回基站。
- 能量消耗模型包含三部分：
  - **播种能量 Es**：与播种面积和种子重量相关；
  - **航拍能量 Eap**：高光谱相机数据采集能耗；
  - **飞行能量 Ef**：与距离和当前载荷相关，公式为 efij = (M + q̄ij)^(3/2) * sqrt(g^3/(2ρςh))。
- 优化目标（RAMP）为最大化加权恢复面积：C = Σ [1 + (li − 0.3)] σi，权重因子 (li − 0.3) 优先恢复退化更严重的区域。
- 完整数学模型为 MINLP，含能量约束、载荷约束、载荷动态平衡、子环消除、访问次数限制等（式 6a–6j）。

### 2.3 单 UAV 恢复规划：BFPRL
- 将单 UAV 恢复问题建模为 MDP，使用 REINFORCE + Greedy Rollout Baseline 训练。
- **状态**：st = (vt, qrem_t, Erem_t, mt, ξt)，包括当前位置、剩余载荷、剩余能量、访问掩码、各区域剩余可恢复单位圆数。
- **动作**：ai = (ji, δi)，其中 ji 为下一访问节点，δi 为该节点恢复面积（单位圆数）。通过可行性掩码确保满足载荷和能量约束并安全返回。
- **转移**：确定性转移，严格更新能量、载荷、掩码和剩余恢复量。
- **奖励函数**：R(π|V) = αr Σ (1 + li − 0.3)σi − αp · pe，其中 pe 为能量违反惩罚（等于路径总长度）。
- **策略分解**：p(π|s) = Π p(ji|s<i) p(δi|ji, s<i)，显式建模轨迹与恢复面积的顺序依赖。

### 2.4 网络架构
- **编码器**：基于 Transformer，使用 Batch Normalization 代替 LayerNorm，融合静态环境特征（坐标、退化程度）和动态 UAV 状态（能量、载荷），输出全局上下文表示。
- **解码器**：Pointer Network + GRU 保持序列状态，结合注意力机制计算节点选择概率，并通过恢复面积分配头（area-allocation head）预测最佳恢复量 δ。
- 联合动作概率为 pθ(ai|s<i) = pθ(ji|s<i) pθ(δi|ji, s<i)。

### 2.5 训练算法
- 使用 **Actor-Critic + Adam 优化器**，结合梯度裁剪。
- Actor 通过策略梯度最大化期望奖励，使用 critic 提供的基线 b(s) 计算优势函数 A(π|s) = R(π|s) − b(s)。
- Critic 通过 MSE 损失拟合基线值。
- 训练流程见 Algorithm 1，验证阶段采用贪心解码，保留验证集上平均奖励最高的模型参数。

### 2.6 多 UAV 协作机制
- **初始分配**：通过 K-means 聚类将全局区域划分为多个子集（每 UAV 一个）。
- **信息共享与动态重分配**：定义匹配代价函数 K(u, vi) = α·d(pu, pi) + β·(1/li) + ϵ·(1/ai)，综合距离、退化程度与区域大小。
- 协作调度通过五步迭代实现：
  1. 初始划分；
  2. 各 UAV 基线轨迹优化；
  3. GCC 根据 K 值重新分配任务；
  4. UAV 对新分区重新规划轨迹并计算潜在收益；
  5. 全局决策：仅当重新分配后的总恢复收益不低于基线时采用新分配。
- 执行阶段：基于信号量 SPu（预计任务时间）选择当前 UAV，并在其子集中选择 K 值最小的区域执行恢复，重复直至任务完成或能量耗尽。

7. **提供轨迹可视化和收敛曲线**，有助于定性评估算法行为。

## 8. 不足与局限

1. **缺乏消融实验**：未分离验证知识引导模块、双层分解、奖励分量等对性能的具体贡献，难以准确定位算法关键因素。
2. **最优性评估标准有限**：所用 Gap 是相对最优基线而非相对于精确最优解（NP-hard 使精确解不可得），故“0.00% gap”的表达可能引起误解。
3. **存在非全优场景**：在 U4-R100、U4-R160、U6-R80、U8-R60 等配置中 KC-BFPRL 并非最佳（Gap>0），论文未解释原因或提出针对性改进。
4. **泛化实验不足**：只展示“固定策略跨规模测试”的定性结论，未系统报告量化结果，也未验证到更大规模（如 200+ 区域）或不同地理分布（非均匀、有障碍物）的迁移能力。
5. **训练算力信息缺失**：未提供训练时间、能耗、参数量等，影响可复现性和资源评估。
6. **假设简化**：假设无人机匀速飞行、固定高度、同构化，未考虑风场、通信延迟、动态障碍等真实不确定性；文中提到未来会考虑动态环境，说明当前适用性受限。
7. **约束保证依赖掩码和惩罚**：虽然通过掩码和惩罚机制尽量保证可行性，但在数值不稳定情况下仍可能产生不可行动作（论文中提及强制终止），硬约束的绝对严格性未完全证明。
8. **基线适配的公平性**：MAPDP 和 CAMP 是经过改编的，可能未达到其最佳性能，比较的公平性有一定保留；且所有基线均训练 10000 epochs，但未报告是否完全收敛。
