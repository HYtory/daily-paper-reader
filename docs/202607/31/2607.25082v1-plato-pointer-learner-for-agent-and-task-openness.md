## 摘要
开放智能体系统（OASYS）在现实世界领域中日益普遍，在这些领域中，智能体和任务的集合会随时间不可预测地变化。这种开放性，包括智能体开放性（AO）和任务开放性（TO），对多智能体强化学习（MARL）构成了根本性挑战，因为MARL通常假设固定的状态和动作空间。现有方法仅部分解决了开放性问题：填充和掩码方法引入了人为界限，而最近的基于图或超图的方法处理了开放性的一个维度，但仍依赖于限制性假设。在本文中，我们提出了面向智能体与任务开放性的指针学习器（PLATO），这是一种基于指针网络的演员（actor）与集中式图神经网络（GNN）评论家（critic）相结合的方法，在集中式训练与分散式执行的范式下，使用多智能体近端策略优化进行训练。我们基于指针的演员直接在当前任务集上输出分布。这直接支持变化的动作空间，无需掩码或重新训练。我们的GNN评论家将智能体-任务交互编码为一个随任务和智能体组成而改变形状的图。这些组件共同考虑了AO和TO，而无需现有方法的界限。我们在任务与智能体开放马尔可夫博弈（TaAgO-MG）中形式化了PLATO，扩展了先前任务开放的公式，并证明它在由此产生的无界状态和动作空间上是良定义的。我们使用开放智能体系统评估方法倡议（MOASEI）的野火扑救领域评估PLATO，该环境专为开放多智能体系统评估而设计，我们展示了比OASYS中最先进的基线更强的性能和更一致的零样本泛化能力。

## Abstract
Open agent systems (OASYS) are increasingly prevalent in real-world domains where the sets of agents and tasks change unpredictably over time. Such openness, including agent openness (AO) and task openness (TO), poses a fundamental challenge to multi-agent reinforcement learning (MARL), which typically assumes fixed state and action spaces. Existing methods address openness only partially: padding and masking approaches introduce artificial bounds, while recent graph-based or hypergraph methods handle one dimension of openness but still depend on restrictive assumptions. In this paper, we introduce Pointer Learner for Agent and Task Openness (PLATO), a pointer-network-based actor combined with a centralized graph neural network (GNN) critic, trained with multi-agent proximal policy optimization under a centralized training and decentralized execution paradigm. Our pointer-based actor outputs distributions directly over the current task set. This directly supports changing action spaces without masking or retraining. Our GNN critic encodes agent-task interactions as a graph that changes shape with task and agent composition. Together, these components consider AO and TO without the boundedness of existing approaches. We formalize PLATO in a Task-and-Agent-Open Markov Game (TaAgO-MG), extending prior task-open formulations, and prove it is well-defined over the resulting unbounded state and action spaces. We evaluate PLATO with the Methods for Open Agent Systems Evaluation Initiative (MOASEI) wildfire suppression domain, an environment designed for open multi-agent system evaluation, and we demonstrate strong performance and more consistent zero-shot generalization than state-of-the-art baselines in OASYS.

## 1. 核心问题与研究动机（研究背景与整体含义）

- **开放智能体系统（OASYS）** 在现实世界中日益普遍，其核心特征是**智能体的集合（Agent Openness, AO）** 和**任务的集合（Task Openness, TO）** 会随时不可预测地变化——智能体可能中途加入或退出（如灭火剂耗尽后离场补给），任务可能随时出现或消失（如火灾随机燃起、蔓延或熄灭）。
- **根本挑战**：传统多智能体强化学习（MARL）默认假设**固定的状态空间和动作空间**，而开放性导致这两个空间在运行过程中不断变化，使得最优策略失效，甚至策略的定义都成问题。
- **现有方法的不足**：
  - *Padding/Masking*：人为引入边界，无法真正应对无界变化；
  - *图/超图方法*（如MOHITO）：只解决单一维度的开放性，MOHITO仅显式建模TO而对随机AO处理不足；DGN、DICG虽具一定灵活性，但仍假设固定动作集或受限的交互结构；
  - 尚无方法能**无需重训练、无需人工边界地联合处理AO与TO**。
- **本文的定位**：首次在MARL中提出一种能够同时、联合处理智能体开放和任务开放的架构——PLATO，并在无界状态与动作空间上提供理论保证。

## 2. 方法论：核心思想、关键技术细节与算法流程

### 2.1 核心思想

- **核心洞见**：将动作选择从"固定索引分类"重新定义为**基于内容的指针选择（content-based pointing）**——每个智能体构造一个上下文查询向量（query），通过与当前可用任务的键向量（key）进行注意力匹配，直接在当前任务集合上输出策略分布。
- **总体架构**：**指针网络演员（Pointer Actor）** + **集中式图神经网络评论员（Centralized GNN Critic）**，在**集中式训练/分散式执行（CTDE）** 范式下，使用**MAPPO**（多智能体PPO）进行联合训练。

### 2.2 形式化框架：TaAgO-MG

- 提出 **Task-and-Agent-Open Markov Game（TaAgO-MG）**，扩展了MOHITO的TaO-MG：
  - 记为 ⟨M, X, N, Ψ⟩，其中 **N**（智能体集合）和 **X**（任务集合）均随时间变化，而非固定集合；
  - 生成器 Ψ 将基础博弈 M 与当前开放集合 (Xt, Nt) 映射为时间索引博弈 Mt = Ψ(M, Xt, Nt)，涵盖状态更新（ΨS）、动作集更新（ΨA）、转移函数生成（ΨT）和奖励函数生成（ΨR）。
- **定理保证**：证明PLATO的actor和critic在整个（可数无穷的）开放智能体—任务空间上是**良定义的（well-defined）** 且**置换不变的（permutation-invariant）**。

### 2.3 指针演员（Pointer Actor）——详细流程

1. **观察因子分解**：将智能体 i 的局部观察 oti 分解为智能体特征矩阵 otN ∈ R^{|Nt|×fN} 与任务特征矩阵 otX ∈ R^{|Xt|×fX}；
2. **编码器（Encoder）——处理AO**：对智能体集合计算四个置换不变的聚合统计量（均值、方差、最小值、最大值）得到固定维度向量 dt，再经 MLPs 编码为查询向量 qt = MLPs(dt)；
3. **任务编码（处理TO)**:对每个当前任务 x 独立编码为键 ktx = MLPx(otx)，加上一个持久化的 NO-OP 键，构成键集合 Kt；
4. **指针解码器**：通过一步加法注意力（additive attention）计算每个任务的注意力分数 utx = vᵀ·tanh(WK·ktx + Wq·qt)，然后对所有分数做 softmax 归一化，得到当前任务集∪{NO-OP}上的分类分布——**分布的支持集与当前任务集合完全一致**。

### 2.4 GNN评论员（GNN Critic）

- 将全局状态建模为**二部智能体—任务图** Gt = ⟨Xt, Nt, Et⟩，图中节点数量随 |Nt| 和 |Xt| 变化；
- 智能体节点与任务节点通过MLP编码到共享潜在空间，经**两层GCN消息传递**（带残差连接）传播交互信息，再通过**全局均值池化**得到固定大小的图摘要，最后映射为标量价值 V；
- 这避免了固定长度拼接，天然支持可变数量的智能体与任务。

### 2.5 训练流程

- 使用 **GAE** 计算优势，PPO-clip目标更新actor，MSE损失更新critic；
- 每时间步的训练复杂度为 **O(|Nt|² + |Nt|·|Xt|)**（定理2），所有神经网络维度视为常数。

### 3.1 实验场景

- **公平**：所有方法使用Optuna（TPE采样器，50 trials）在S3/3×3上进行超参数调优，搜索空间锚定各方法官方默认值；使用相同的执行种子集（种子匹配的逐回合观察）控制方差。

## 6. 主要结论与发现

1. **性能**：在3×3网格的S2、S3及4×4网格的S1–S3上，PLATO以统计显著性取得最高回报；S0（封闭场景）各智能方法表现相当；2×3网格上PLATO在S1–S3显著领先。
2. **效率**：PLATO在3×3网格的S0、S2、S3及4×4的S2–S3上获得统计显著最高的单次灭火回报；且在所有网格和设置下保持正值。
3. **零样本泛化**：PLATO在多种跨网格迁移中表现最一致：
   - 在2×3训练→3×3测试时，PLATO在S1–S2显著领先；
   - 在3×3训练→5×5测试时，PLATO在S1–S3显著领先；
   - MOHITO在部分设置下回报为负（如2×3→4×4的S2）；DGN在开放性下普遍退化。
4. **消融发现（存在交互效应）**：
   - **LSTM的收益并非普适**：原生评估中MLP与LSTM无显著差异；但在零样本S3（联合开放性最强场景）下，结合加法注意力时LSTM显著更优；
   - **评分器优劣取决于编码器**：零样本S3下（lstm+add）显著优于（lstm+dot）；而在封闭S0零样本下（mlp+dot）显著优于（mlp+add）——**(lstm+add) 在最强开放场景、 (mlp+dot) 在封闭场景下分别最优**。

## 7. 优点与亮点

- **创新性强**：首次将指针网络引入MARL开放性场景，以内容寻址方式直接输出当前任务集分布，**无需填充、掩码或重训练**即可适应动态动作空间；
- **全面性**：联合处理AO与TO，且通过TaAgO-MG形式化，同时给出**良定义性、置换不变性和计算复杂度的理论证明**——这在开放多智能体的MARL文献中相对少见；
- **设计合理性**：
  - 智能体编码使用多重统计量（均值/方差/最小/最大）缓解不同智能体集合产生相同表示的"混叠"问题；
  - 评论员图节点/边数随系统构成变化，均值池化得到固定维度价值估计；
  - 利用统计检验方法论区分各方法间的差异；
- **实验严谨**：统计显著性检验、种子匹配、超参数调优、消融因子设计均有说明；
- **开源生态**：使用MOASEI公开基准环境，实验结果可复现。

## 8. 不足与局限

- **实验覆盖有限的场景类型**：
  - 仅在**野火抑制域**单一环境上评估，未在Eck et al.所列的其他OASYS领域验证；
  - 只研究了"每任务单动作"的场景（fire suppression），不支持每个任务具有多动作集合的一般情形；
- **假设限制**：
  - 假设**完全的智能体与任务可观测性**，未处理部分可观测（POMDP）或潜在状态/信念扩展的情形；
  - 未考虑**帧开放性（Frame Openness，FO）**——即智能体内部目标、偏好和能力的变化；
  - 智能体在网格中**位置固定、不可移动**，简化了协同空间结构；
- **基线局限**：虽然DICG/DGN属于SOTA，但并非专为开放性设计，其固定边界假设可能使其在公平比较中处于劣势；MOHITO虽为TO设计，但未显式处理AO；方法比较上仍缺少与Transformer类架构的直接对比；
- **零样本结果的不一致性**：PLATO在零样本场景未必总是最优（例如DICG在部分目标网格的S1/S3更优），说明跨网格泛化仍有提升空间；
- **消融分析的显著性不足**：在原生评估中，不同编码器/评分器变体之间几乎没有统计显著差异，消融结论主要依赖零样本场景下的部分设置，解释时需谨慎；
- **算力开销大**：全部在CPU上运行，单次训练3–5天，总套件近万CPU日，可能限制方法的快速迭代和更大规模实验的开展。
